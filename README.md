# 学习通本地学习助手

适用于 Tampermonkey 的本地脚本，提供学习通章节页的视频/音频播放控制、播放中弹题处理、章节测验辅助和可选的连续学习流程。当前版本：**0.8.9**。

> AI 回答可能出错。连续学习模式会自动提交测验，请在开启前确认课程要求和自己的选择。

## 安装

1. 安装并启用 Tampermonkey。在 Chrome 的扩展设置中开启“允许用户脚本”。
2. 打开 [chaoxing-local-helper.user.js](./chaoxing-local-helper.user.js)，复制全部内容，在 Tampermonkey 中新建脚本并保存。
3. 刷新学习通章节页。出现“学习通本地助手”面板后即可使用。按住面板标题可拖动位置。

脚本目前只匹配 `mooc1.chaoxing.com` 的章节、作业和媒体页面。它没有外部脚本依赖，也没有自动更新地址。

## 功能

- **媒体播放**：在当前页尝试播放视频或音频，可选择静音、同页下一段媒体接续播放。浏览器或平台可能阻止自动播放，遇到提示时需使用原播放器的播放键。
- **播放中弹题**：检测可读取的文字选择题，并在配置 DeepSeek 后自动请求建议、填选和尝试恢复播放；无法确认题目或播放状态时会停止并提示。
- **章节测验**：可把题目逐题发送给 DeepSeek 获取建议，自动填入有效选项；普通模式不会自动提交。也可按题目 ID 在本机保存、导入或导出答案表。
- **逐节连续学习**：点击“开始连续学习”后，每节媒体任务点完成便处理该节测验，**自动提交测验**，再进入下一节。
- **先媒体后测验**：点击“先看完媒体再做测验”后，先从首个未完成章节开始逐节完成媒体任务点，再从首个未完成章节开始处理测验并自动提交。适合允许延后做测验的课程。运行期间不要在同一标签页切换到其他课程。

普通模式下，自动询问新题和收到建议后自动填选默认开启。可在面板中分别关闭。播放中弹题仍会在媒体阶段处理。DeepSeek 出现 429、500、502、503、504、网络故障或超时时会自动等待并重试，最多 12 次请求；弹题请求连续失败时会在 5 分钟后再试。章节跳转后会核对是否真的进入下一节。学习通偶尔在快速切章后显示空白卡片；脚本会最多刷新当前课程页两次，并等待目录恢复。新媒体会尝试播放器按钮、静音播放和延时重试；浏览器仍可能要求用户手动点击播放。

## 设置 DeepSeek Key

在助手面板点击“设置 DeepSeek Key”，或在 Tampermonkey 的脚本菜单中选择同名命令，输入**你自己的** API Key。清除时使用脚本菜单中的“清除 DeepSeek API Key”。

Key 不写在此仓库的代码里，保存在你浏览器的 Tampermonkey 脚本存储中。配置 Key 后，自动询问和弹题功能可能自动发起请求；请求会产生 API 费用。

## 隐私与网络请求

脚本只申请连接 `api.deepseek.com`。请求发往 `https://api.deepseek.com/chat/completions`，使用 `deepseek-flash` 模型。

- 章节测验会把**单题题干和选项渲染成图片**，连同 API Key 发给 DeepSeek。
- 播放中弹出的文字选择题会把**单题题干和选项文本**，连同 API Key 发给 DeepSeek。
- Key、本地答案表、AI 建议缓存和播放偏好保存在 Tampermonkey 中。脚本不主动读取或发送 Cookie、账号信息或整页截图。

题目本身仍可能含有你不想发送给第三方的内容。请在开启自动询问前检查课程题目及 DeepSeek 的服务条款。

## 已知限制

- 主要支持单选、多选和判断题。图片题、填空题、简答题及无法准确读取的题目可能无法自动处理。
- 学习通页面结构改版、跨域框架和加密字体问题可能让答题功能失效。
- 平台可能在窗口失焦、切换标签页或最小化时暂停或不计入观看时长。脚本不跳过观看要求，也不能保证无人值守完成课程。
- AI 建议和自动提交可能影响成绩。使用前请自行核对，遵守课程及学校规定。
